## About me

I'm an IT technician with a passion for computer and network security, open-source software, and solving everyday technical problems.

I enjoy creating portable tools that are easy to use without a complicated setup. Most of my projects are inspired by real-world troubleshooting and the needs of everyday computer users and IT technicians.

- 🔧 Windows utilities, system diagnostics, and repair tools
- 🛡️ Computer security, networking, and hands-on learning
- 🧪 Experiments, automation scripts, and technical documentation
- 📚 Continuing to learn Python, AutoIt, and Linux

## Featured projects

| Project | What it does |
| --- | --- |
| [**Window Guard**](https://github.com/Gexos/window-guard) | PIN-based application privacy tool for Windows. |
| [**System Info Dashboard**](https://github.com/Gexos/System-Info-Dashboard) | Portable dashboard for system information, resource usage, and process monitoring. |
| [**Windows First Aid Toolkit**](https://github.com/Gexos/Windows-First-Aid-Toolkit) | A practical toolkit for common Windows troubleshooting and repair tasks. |
| [**Disk Health Viewer**](https://github.com/Gexos/Disk-Health-Viewer) | SMART disk health inspection and diagnostic reports. |
| [**BIOS Storage Check**](https://github.com/Gexos/bios-storage-check) | Helps identify visible storage controllers, drivers, and likely storage modes. |
| [**Power Panel**](https://github.com/Gexos/Power-Panel) | Quick access to common Windows power actions. |
